# Запуск и подключение

Инструкция для личного использования: один компьютер с Figma, телефоны в той же сети Wi-Fi, приложение запускается через Expo Go.

Что проверено и что нет — в разделе 11 [спецификации](spec.md).

## Что понадобится

- Mac с Node.js 22 или новее и настольным приложением Figma.
- iPhone или Android с приложением Expo Go.
- Компьютер и телефон в одной сети Wi-Fi. Гостевая сеть не подходит: в ней устройства обычно не видят друг друга.

## Первая настройка

### 1. Сервер

```
cd server
npm install
cp .env.example .env
```

Откройте `server/.env` и укажите имя сетевого интерфейса Wi-Fi:

```
LAN_INTERFACE=en0
```

Как узнать имя интерфейса:

- запустите сервер без этой настройки, он напечатает все интерфейсы с адресами;
- либо выполните `networksetup -listallhardwareports` и найдите блок `Hardware Port: Wi-Fi`, имя стоит в строке `Device`.

На Mac это обычно `en0`. Интерфейсы с именами `utun…` относятся к VPN, их указывать не нужно.

Сервер открывает порт только на двух адресах: `127.0.0.1` (для плагина) и адрес указанного интерфейса (для телефона). Без `LAN_INTERFACE` он доступен только с самого компьютера.

### 2. Плагин Figma

```
cd figma-plugin
npm install
npm run build
```

В настольном приложении Figma: **Plugins → Development → Import plugin from manifest…** и выберите `figma-plugin/manifest.json`.

Импорт локального плагина работает только в настольном приложении. После изменения кода плагина снова выполните `npm run build` и перезапустите плагин.

### 3. Мобильное приложение

```
cd mobile
npm install
```

Установите Expo Go из App Store или Google Play.

## Обычный запуск

### 1. Запустите сервер

```
cd server
npm start
```

Сервер напечатает:

```
Сервер Mobile Gallery запущен.
  Для плагина Figma:  http://localhost:8787
  Для телефона:       http://192.168.1.10:8787   (интерфейс en0)
  Токен лежит в файле: …/server/.token
```

Окно терминала должно оставаться открытым. Остановить сервер: `Ctrl+C`.

### 2. Возьмите токен

Токен создаётся при первом запуске и не меняется при перезапусках. Скопировать его в буфер обмена:

```
cat server/.token | pbcopy
```

### 3. Запустите плагин

В Figma откройте нужный файл и страницу, затем **Plugins → Development → Mobile Gallery**. При первом запуске вставьте токен и нажмите «Сохранить». Плагин должен показать «Подключено».

Изображения вставляются на страницу, которая открыта в момент вставки. Плагин работает, пока открыто его окно.

### 4. Запустите приложение

На Android можно пользоваться собственной сборкой, она описана ниже, и тогда этот шаг не нужен. На iPhone приложение запускается через Expo Go.

В новом окне терминала:

```
cd mobile
npx expo start --go
```

Ключ `--go` нужен, потому что в проекте есть `expo-dev-client`: без ключа dev-сервер ждёт development build, а не Expo Go.

Отсканируйте QR-код: на iPhone камерой, на Android из Expo Go.

В приложении откройте «Настройки», введите адрес из строки «Для телефона» и токен, нажмите «Проверить соединение», затем «Сохранить». Настройки сохраняются на телефоне.

Чтобы не вводить токен на телефоне вручную, можно задать начальные значения в файле `mobile/.env.local` (образец — `mobile/.env.example`). Этот способ только для разработки: значения встраиваются в сборку приложения.

## Собственная сборка для Android

Приложение собирается в облаке через EAS Build и устанавливается на телефон как обычное приложение. Нужна бесплатная учётная запись [expo.dev](https://expo.dev). Инструменты на Mac ставить не нужно.

| Профиль | Что это | Нужен dev-сервер на Mac |
|---|---|---|
| `development` | Сборка для разработки: код берётся с Mac, изменения видны сразу | Да: `npx expo start` в папке `mobile` |
| `preview` | Самостоятельное приложение | Нет |

Собрать:

```
cd mobile
npx eas-cli@latest login
npx eas-cli@latest build --profile preview --platform android
```

В конце EAS покажет ссылку и QR-код на файл APK. Откройте его на телефоне и установите. Новую сборку ставьте поверх старой: Android предложит обновить приложение, и настройки сохранятся.

**Адрес сервера в собственной сборке — только по имени компьютера:**

```
http://<имя-компьютера>.local:8787
```

Имя компьютера показывает команда `scutil --get LocalHostName`. По IP-адресу preview-сборка не подключится: Android разрешает ей HTTP только для имён `*.local`, остальные адреса защищены как обычно. Зато адрес по имени не меняется при смене IP.

На iPhone собственная сборка требует платной учётной записи Apple Developer либо локальной сборки в Xcode с переустановкой раз в 7 дней. Пока iPhone работает через Expo Go.

## Если сменился IP-адрес компьютера

Адрес может измениться после переподключения к Wi-Fi или перезагрузки роутера.

1. Перезапустите сервер: он определяет адрес при запуске и напечатает новый.
2. Введите новый адрес в настройках приложения на телефоне.

Чтобы адрес не менялся, закрепите его за компьютером в настройках роутера. Обычно это называется «резервирование DHCP» или «статическая аренда»: в списке подключённых устройств выберите компьютер и закрепите текущий адрес.

Проброс портов на роутере настраивать не нужно и не следует: сервер не рассчитан на доступ из интернета.

## Firewall macOS

Проверить состояние: **Системные настройки → Сеть → Firewall**.

Если firewall включён, при первом запуске сервера macOS может спросить, разрешить ли программе `node` принимать входящие подключения. Нужно разрешить. Если запрос был отклонён, разрешение меняется там же, в разделе «Параметры».

Работа с включённым firewall не проверялась: на компьютере разработки он выключен.

## Типичные проблемы

| Что видно | Причина | Что делать |
|---|---|---|
| Плагин: «Сервер недоступен» | Сервер не запущен | Запустите `npm start` в папке `server` |
| Плагин: «Токен не подошёл» | Введён не тот токен | Скопируйте токен из `server/.token`, нажмите «Сменить токен» |
| Телефон: «Сервер недоступен» | Сервер не запущен, другой адрес или другая сеть | Пройдите подсказку «Как подключиться» в настройках приложения |
| Телефон: «По этому адресу отвечает другое устройство» | IP компьютера сменился, старый адрес занят другим устройством | Возьмите адрес из окна сервера |
| Телефон: «Токен неверный» | Токен в настройках не совпадает с `server/.token` | Введите токен заново |
| Телефон: «Плагин в Figma не запущен» | Окно плагина закрыто | Запустите плагин. Изображения ждут в очереди до 30 минут |
| Телефон: «Статус неизвестен» | Сервер был перезапущен, очередь очищена | Нажмите «Повторить». Дубликат не появится |
| Сервер: «Порт 8787 уже занят» | Уже запущен другой экземпляр сервера | Остановите его |
| Сервер: «У интерфейса … нет IPv4-адреса» | Wi-Fi выключен или имя интерфейса указано неверно | Включите Wi-Fi или исправьте `LAN_INTERFACE` |
| Изображение вставилось, но его не видно | Новый блок сетки начинается ниже всего содержимого страницы | Плагин сам прокручивает к нему, когда очередь опустела |

На iPhone дополнительно проверьте доступ к локальной сети: **Настройки → Конфиденциальность и безопасность → Локальная сеть**, переключатель у Expo Go должен быть включён.

## Что нужно знать о работе

- **Очередь хранится в памяти сервера.** Перезапуск её очищает. Телефон покажет «Статус неизвестен», кнопка «Повторить» вернёт изображение в очередь.
- **Повтор не создаёт дубликат.** Плагин помнит, какие изображения уже вставил, и при повторе только подтверждает вставку.
- **Чтобы вставить то же фото ещё раз, выберите его в галерее заново.**
- **Форматы:** PNG, JPEG и GIF до 20 МБ и до 50 мегапикселей. GIF вставляется как статичное изображение. Фото в HEIC iPhone отдаёт как JPEG.
- **Изображения больше 4096 px** плагин уменьшает: это ограничение Figma.
- **Список в приложении не сохраняется** между запусками. Уже отправленные изображения при этом будут вставлены.

## Безопасность

- Токен — временный механизм для личного использования в домашней сети. Трафик идёт по HTTP без шифрования, поэтому устройство в той же сети, перехватившее его, получит токен и изображения.
- Не запускайте сервер в общественных сетях Wi-Fi.
- Не публикуйте сервер в интернет: ни пробросом портов, ни туннелем без дополнительной защиты.
- Файлы `server/.token`, `server/.env` и `mobile/.env.local` исключены из git. Не добавляйте их в репозиторий.
